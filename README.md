# 쿠션랩 · 3쿠션 연습장

설치나 빌드 없이 브라우저에서 실행하는 HTML Canvas 기반 당구 연습 게임입니다.

## 실행

저장소를 다운로드한 뒤 `index.html`을 브라우저로 열면 됩니다. 외부 라이브러리나 서버가 필요하지 않습니다.

## 조작

- 당구대 클릭: 흰 공의 진행 방향 조준
- 조준 각도 슬라이더: 각도 미세 조절
- 샷의 세기: 힘 조절
- 당점 원 클릭: 회전 조절, 중앙 버튼으로 초기화
- 샷 하기 또는 스페이스바: 샷 실행
- 같은 배치: 직전 샷 시작 위치로 복원
- 공 배치: 공을 드래그하여 배치, 배치 완료 후 샷
- 연습 배치: 기본 / 넓게 돌리기 / 짧게 돌리기 / 랜덤
- 예상 경로 및 이동 궤적 표시를 켜거나 끌 수 있습니다.

## 득점과 모델

흰 공이 서로 다른 두 목적구에 닿고, 두 번째 목적구에 닿기 전에 쿠션을 3회 이상 맞히면 득점합니다. 샷마다 쿠션 횟수와 목적구 충돌 순서가 표시됩니다.

회전·마찰·쿠션 반사는 연습용 2D 근사 모델이며 실제 당구의 정밀한 물리를 재현하지 않습니다. 점선은 공 충돌 또는 최대 3쿠션까지의 기하학적 참고선이며 힘과 회전을 반영한 완전한 예측은 아닙니다. 기록은 현재 페이지 세션 동안 유지됩니다.

## 파일

- `index.html`: 화면, 스타일, 물리 시뮬레이션을 포함한 독립 실행 파일
